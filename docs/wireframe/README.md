# Wireframe

Buka file HTML di browser untuk melihat tata letak. Ukuran layar scan 390x844 px (tampilan ponsel/PDA); dashboard responsif.

| File | Layar |
| --- | --- |
| 01-scan-penerimaan.html | Scan penerimaan barang (GRN) |
| 02-picking.html | Picking barang keluar, dua langkah: scan lokasi lalu scan barang |
| 03-stock-opname.html | Stock opname dengan hitung buta |
| 04-dashboard-admin.html | Dashboard web admin |

Nama barang, nomor dokumen, dan angka di wireframe hanya contoh. Warna aksen #1B5FD0, font Inter.
Versi yang bisa diedit dan dikomentari ada di kanvas Design di Claude.
